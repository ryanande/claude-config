1. **A model is regenerating 57 tests against a substituted fixture — and the tests are the oracle** — _Tolling Systems - Daily Stand Up_ (`meeting_OWRlZjYx…`, pinned).
   Lynn Clark reported finding 57 existing Miller tests authored by Navya, and is "having Claude recreate them using BDD" — substituting TEC for Miller and account #597805 for the original account. Her rationale: "Much easier than re-writing them."
   **Why it matters:** This is the highest-consequence item in a thin window, and it is not a tooling question — it is a question about what the test suite is evidence *of*. A regenerated test asserts what the model inferred the original was checking, not what the original actually characterized. When the customer and account are simultaneously swapped, the two changes are indistinguishable in the output: a test that now passes may be passing because TEC genuinely behaves the same way, or because the assertion drifted to match whatever the new fixture happens to produce. The lens's testing guidance (Good vs Bad Tests, Test Suite Health) exists for exactly this, but the sharper framing is the one this digest has now flagged three days running — AI output entering a durable artifact as verified fact. Here the artifact is the suite that gates everything else, which makes it the worst place for the pattern to land. It is also the identical failure shape the runtime-verification rule in `CLAUDE.md` was written about: a green gate over a proxy.
   **Action:** Ask for the original 57 to be kept and run alongside the regenerated set until both agree — the old tests against Miller, the new against TEC — so the substitution is proven behavior-preserving rather than assumed. If the Miller fixture can no longer run, that is worth knowing explicitly, because it means the regenerated suite has no baseline to be checked against and its confidence level should be recorded as self-reported. Cheap now, unrecoverable once the originals are deleted.

This is Class 1 data by definition — the moment it lives in someone's head, the arch-rover report and reality diverge without anyone noticing.
